# Soof Studio - Learn Kutch Soof Embroidery

An interactive web application designed to help users learn and practice the traditional art of Kutch Soof Embroidery. Built with HTML, CSS, and p5.js, this interactive canvas allows users to explore and practice intricate Soof embroidery patterns digitally.

## Features
- **Interactive Embroidery Canvas**: Practice stitching patterns using an intuitive digital interface powered by p5.js.
- **Traditional Motifs**: Learn authentic Kutch Soof geometric designs.
- **Real-time Feedback**: See your stitches rendered instantly on the screen.

## Technologies Used
- HTML5 & CSS3
- JavaScript
- [p5.js](https://p5js.org/) for the interactive drawing canvas

## How to Run Locally
Since this is a client-side application, you can simply open the `index.html` file in any modern web browser to start using it.

1. Clone this repository:
   ```bash
   git clone https://github.com/CommandControlByRohan/soof-studio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd soof-studio
   ```
3. Open `index.html` in your browser.

## About Soof Embroidery
Soof is a painstaking, geometry-based embroidery from the Kutch region of Gujarat, India. The artisan works from the back of the fabric, counting threads to create highly intricate, symmetrical, and beautiful geometric patterns without the use of an outline or a pre-drawn design.
